# Nexo Klar · Pages JSX actualizadas

Este documento mantiene el registro de las páginas React (`src/pages/*.jsx`) que han sido intervenidas durante la modernización de Nexo Klar.

## Criterio de uso

- Registrar aquí cada `Page.jsx` que sea actualizado de forma funcional, visual o arquitectónica.
- Mantener el nombre real del archivo del repositorio.
- No incluir componentes auxiliares salvo que formen parte de una página.
- Este listado debe seguir actualizándose a medida que avancemos con nuevas fases.
