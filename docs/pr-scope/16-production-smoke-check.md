# Verificación controlada de producción

## Objetivo
Tener una pauta reproducible antes de habilitar una empresa productiva.

## Criterios de aceptación
- Revisión de `/api/ready` para base, almacenamiento y antivirus.
- Pruebas controladas de correo, WhatsApp, firma, acreditación y descarga.
- Evidencia de resultado y responsable.
- Sin exponer secretos ni datos reales innecesarios.

## Pruebas
Entorno listo, dependencia caída y recuperación.
