# Alertas accionables

## Objetivo
Convertir cada alerta en una tarea resoluble desde el lugar donde se detecta.

## Criterios de aceptación
- Prioridad bloqueante, próxima, informativa y resuelta.
- Enlace directo a la persona, orden, contrato o recurso afectado.
- Acción sugerida y responsable visible.
- Resolución auditada y sin duplicados para el mismo hecho.

## Pruebas
Documento faltante, vencimiento, doble asignación y alerta resuelta.
