# Cobertura E2E crítica

## Objetivo
Extender las pruebas de navegador a los flujos más importantes para clientes.

## Criterios de aceptación
- Personas, restricciones, EPP, turnos, Libro de Obra, inventario e importación.
- Validación por roles de edición y consulta.
- Carga real simulada de archivos.
- Ejecución automática en integración continua.

## Pruebas
Suites de escritorio y móvil con datos aislados por tenant.
