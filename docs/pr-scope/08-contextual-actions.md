# Acciones en contexto comercial

## Objetivo
Mantener cliente y contrato preseleccionados al crear entidades relacionadas.

## Criterios de aceptación
- Desde Cliente se crea contrato u OS con contexto heredado.
- Desde Contrato se crea OS con cliente y contrato heredados.
- El usuario puede cambiar contexto antes de guardar.
- La navegación conserva la relación correcta al volver.

## Pruebas
Crear contrato y OS desde ficha de cliente y desde ficha de contrato.
