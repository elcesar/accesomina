# Estado de integraciones

## Objetivo
Dar visibilidad segura de la salud de correo, WhatsApp, firma, ERP, acreditación, almacenamiento y antivirus.

## Criterios de aceptación
- Estado, última ejecución, resultado y error legible.
- Acción de prueba controlada para administradores.
- No muestra claves, tokens ni datos sensibles.
- Enlaces al evento y entidad relacionados.

## Pruebas
Servicio configurado, no configurado, error externo y reintento exitoso.
