# Flujo único de habilitación

## Objetivo
Presentar el ciclo completo de una persona: documentos, salud, formación, EPP, asignación, acreditación y credencial.

## Criterios de aceptación
- Un único estado operativo con causa y próxima acción.
- La misma regla alimenta ficha, alertas, panel y planificación.
- El historial muestra quién cambió el estado y por qué.
- No se puede asignar una persona bloqueada o no habilitada sin autorización explícita.

## Pruebas
Persona disponible, pendiente documental, restringida, acreditada y con credencial vencida.
