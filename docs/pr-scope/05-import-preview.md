# Previsualización de importaciones

## Objetivo
Validar una importación antes de modificar los datos de la empresa.

## Criterios de aceptación
- Mostrar válidos, inválidos, duplicados y referencias no encontradas.
- Informar si la fila crea o actualiza un registro.
- Exigir confirmación solo después de la revisión.
- Conservar el archivo y resultado de importación en la bitácora.

## Pruebas
RUT inválido, fila duplicada, contrato inexistente y archivo correcto.
