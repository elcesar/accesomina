# Búsqueda global

## Objetivo
Encontrar rápidamente personas, RUT, clientes, contratos, órdenes, activos y documentos.

## Criterios de aceptación
- Resultados separados por tipo y restringidos al tenant.
- Respeta permisos de consulta.
- Muestra contexto suficiente y abre la ficha correcta.
- Soporta RUT con y sin puntuación.

## Pruebas
Búsqueda por nombre, RUT, código contractual y usuario sin acceso.
