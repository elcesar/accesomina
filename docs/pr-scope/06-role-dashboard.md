# Panel de control por rol

## Objetivo
Priorizar el trabajo pendiente según responsabilidades del usuario.

## Criterios de aceptación
- Client Admin, RR.HH., Prevención, Acreditación y consulta ven paneles pertinentes.
- No se expone información ni acciones sin permiso.
- Cada indicador enlaza a su lista filtrada.
- El usuario puede volver a una vista general de la empresa.

## Pruebas
Comparar contenido y enlaces de cada rol.
